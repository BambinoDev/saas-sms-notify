🔐 CONNEXION
══════════════════════════════════════════════════════════

Page de connexion:
  → http://localhost:8080/login

Identifiants (Superadmin):
  Email    : admin@notify-sms.local
  Password : password


👤 INTERFACE CLIENT (Utilisateur normal)
══════════════════════════════════════════════════════════

Paramètres de MON organisation:
  → http://localhost:8080/organization/settings/general

Fonctionnalités:
  ✅ Modifier nom, logo, couleurs
  ✅ Gérer membres de MON org
  ✅ Voir MA subscription
  ✅ Paramètres API

Restrictions:
  ❌ Pas de liste d'organisations
  ❌ Pas de bouton "Nouvelle Organisation"
  ❌ Pas d'accès aux autres orgs


👑 INTERFACE SUPERADMIN (Admin Central - vous!)
══════════════════════════════════════════════════════════

Gestion de TOUTES les organisations:
  → http://localhost:8080/admin/organizations

Fonctionnalités:
  ✅ Voir liste de TOUTES les orgs
  ✅ Créer nouvelle organisation
  ✅ Éditer N'IMPORTE quelle org
  ✅ Gérer membres de N'IMPORTE quelle org
  ✅ Supprimer des organisations
  
Plus:
  ✅ Accès aussi à /organization/settings/* (votre propre org)
  ✅ Tous les droits d'un client + droits admin


🗺️ NAVIGATION
══════════════════════════════════════════════════════════

Comme CLIENT:
  /organization/settings/general  → Mes paramètres
  /organization/settings/members  → Mes membres
  /organization/settings/billing  → Ma facturation
  
Comme SUPERADMIN:
  /admin/organizations            → Toutes les orgs
  /admin/organizations/create     → Créer org
  /admin/organizations/1          → Voir org #1
  /admin/organizations/1/edit     → Éditer org #1
