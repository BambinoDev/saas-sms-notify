🔵 ESPACE CLIENT (Interface Bleue)
══════════════════════════════════════════════════════════

Login:
  → http://localhost:8080/login (PAGE BLEUE)
  
  Email: admin@notify-sms.local
  Password: password
  
Après connexion:
  → http://localhost:8080/dashboard
  → http://localhost:8080/organization/settings/general
  
Fonctionnalités:
  ✅ Dashboard principal
  ✅ Gestion cases (ses cases)
  ✅ Gestion SMS (ses SMS)
  ✅ Paramètres de SON organisation
  ✅ Modifier branding (nom, logo, couleurs)
  ✅ Gérer membres de SON org
  
Restrictions:
  ❌ Pas d'accès à /admin/*
  ❌ Ne voit PAS d'autres organisations


🔴 ESPACE ADMIN (Interface Rouge)
══════════════════════════════════════════════════════════

Login:
  → http://localhost:8080/admin/login (PAGE ROUGE 🔒)
  
  Email: admin@notify-sms.local
  Password: password
  (Vérifie is_superadmin = true)
  
Après connexion:
  → http://localhost:8080/admin (Dashboard admin)
  → http://localhost:8080/admin/organizations
  
Fonctionnalités:
  ✅ Dashboard admin avec stats globales
  ✅ Liste de TOUTES les organisations
  ✅ Créer nouvelle organisation
  ✅ Éditer N'IMPORTE quelle org
  ✅ Gérer membres de N'IMPORTE quelle org
  ✅ Supprimer organisations
  ✅ Stats plateforme (revenue, users, etc.)
  
Plus:
  ✅ Accès aussi à l'espace client (si membre d'une org)
