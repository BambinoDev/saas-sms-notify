🔐 ÉTAPE 1 : CONNEXION
══════════════════════════════════════════════════════════

Ouvrez votre navigateur :
  → http://localhost:8080/login

Connectez-vous avec :
  • Email    : admin@notify-sms.local
  • Password : password
  
✅ Vous serez redirigé vers /dashboard


👤 ÉTAPE 2 : INTERFACE CLIENT
══════════════════════════════════════════════════════════

Gérer VOTRE organisation :
  → http://localhost:8080/organization/settings/general

Vous pouvez :
  ✅ Modifier nom, logo, couleurs
  ✅ Voir stats de votre org (42,564 cases)
  ✅ Gérer membres (/members)
  ✅ Voir facturation (/billing)


👑 ÉTAPE 3 : INTERFACE SUPERADMIN
══════════════════════════════════════════════════════════

Gérer TOUTES les organisations :
  → http://localhost:8080/admin/organizations

Vous pouvez :
  ✅ Voir liste de toutes les organisations
  ✅ Créer nouvelle organisation (bouton +)
  ✅ Cliquer sur une org pour voir détails
  ✅ Éditer n'importe quelle org
  ✅ Gérer membres de n'importe quelle org
